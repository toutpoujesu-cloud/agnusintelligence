AGNUS Academy Level 3 · Direct M16 — Write the Prompt That Gets the Right Image
Step 2 of 3 — Direct

Direct the image tool like you'd direct a photographer.

An image generator can't read your brand deck. Every visual requirement — palette, mood, composition, subject — has to be in the prompt itself, or the tool will fill the gap with its own guess.

Task

Write the prompt for a hero banner image for a coastal outdoor apparel brand's autumn campaign.

What a strong prompt names explicitly

SubjectWhat's actually in frame — not just a mood word.
PaletteSpecific colors or tones, not "nice colors."
SettingWhere the scene takes place — grounds the whole image.
StylePhotographic vs. illustrated, lighting, mood — named, not implied.

Why this matters

This is a live simulation, not a real generator — but the lesson transfers directly: whichever tool you actually use (Midjourney, DALL·E, or others), it fills any unstated requirement with its own default. Naming the requirement is what removes the guesswork.
