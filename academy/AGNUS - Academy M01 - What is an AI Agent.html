Step 1 of 4 — Understand4 min

An agent is a loop, not a single answer.

A chatbot answers once. An AI agent plans, acts, checks the result, and decides what to do next — repeating that loop until the task is done or it needs you.

The core loop

01
Plan
→
02
Act
→
03
Observe

The agent repeats this loop — planning a step, taking an action (like calling a tool), and observing the result — until the task is complete. Each pass through the loop can change its next plan.

Step 2 of 4 — See3 min

A real agent trace

Task: "Find this week's top AI news story."

Plan: search recent AI news sources
Act: call search_web("AI news this week")
Observe: 8 results returned
Plan: read the top 3 for relevance
Act: call fetch_page() × 3
Observe: one story clearly dominant
Done: "Story X is the top AI news this week — here's why."

Why this matters

Notice the agent didn't just answer from memory — it planned, took real actions, and used what it observed to decide its next step. That loop is what separates an agent from a single-turn reply.
