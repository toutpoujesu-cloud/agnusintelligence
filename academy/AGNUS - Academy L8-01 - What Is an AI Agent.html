AGNUS Academy Level 8 · Foundation L8-01 — What Is an AI Agent?
Step 1 of 4 — Understand4 min

An agent is a model wrapped in a loop it can run more than once, on its own.

A single AI reply is open-loop: you ask, it answers, done. An agent is closed-loop: it can observe the result of its own action and decide to act again, without you re-prompting it each time.

Why this matters — the Chef Analogy

A model that just answers is like a chef who can describe a recipe perfectly but never enters the kitchen. An agent is that same chef actually cooking: tasting the sauce, adjusting the seasoning, tasting again — repeating a loop of action and observation until the dish is actually done, not just described.

The two properties that define an agent

Autonomy: it can decide its next action based on what it just observed, without a human re-typing the next instruction each time.

Tool use: it can take real actions in the world — calling a function, querying a database, sending a request — not just producing text about what it would do.

Step 2 of 4 — See4 min

The closed loop, in three parts — watch it run

PlanDecide the next action given the current goal and what's known so far.
→
ActExecute that action — a real tool call, not just a description.
→
ObserveRead the actual result and feed it back into the next Plan step.

This loop can repeat many times in a single task with no new input from a human — that's what "closed-loop" means. An open-loop system does one pass (a single model reply) and stops, whether or not the goal was actually reached.

A real trace — fixing a failing test, three loop iterations

[Iteration 1 — Plan] Goal: make test_total() pass. No prior attempt yet.
[Iteration 1 — Act] Edited calc.py line 12, ran test suite.
[Iteration 1 — Observe] Result: FAILED — TypeError: str + int
[Iteration 2 — Plan] New info: a type mismatch, not a logic error. Decide to add explicit casting.
[Iteration 2 — Act] Edited calc.py line 12 again, ran test suite.
[Iteration 2 — Observe] Result: FAILED — assertion mismatch, off by one
[Iteration 3 — Plan] New info: type error is gone; now a boundary condition. Adjust the loop range.
[Iteration 3 — Act] Edited range bound, ran test suite.
[Iteration 3 — Observe] Result: PASSED — goal reached, loop stops on its own.

Notice each Plan step uses the actual error message from the previous Observe — not a generic retry. That's what makes it a real closed loop rather than blind repetition.

Open-loop vs. closed-loop, side by side

Open-loop
  • Single request → single response
  • No awareness of whether the response actually worked
  • A human must decide and type the next step
Closed-loop (agent)
  • Plan → Act → Observe repeats on its own
  • Checks its own result against the goal
  • Decides the next step itself, without a new human prompt
