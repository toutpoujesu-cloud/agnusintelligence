Step 1 of 4 — Understand4 min

L8-04 named three models. The real landscape a builder chooses from is wider — and the differences are structural, not just brand names.

Claude, GPT, and Gemini aren't the whole field. DeepSeek, Kimi, and Grok each make a genuinely different tradeoff — on cost, context length, openness, or access to live data — and picking blind means missing a model that might fit your task better.

Why this matters

Same lesson as L8-05's framework choice, one layer down: "which model is best" is the wrong question. The right one is which specific tradeoff — cost-per-token, context window size, self-hosting ability, real-time data access — actually matters for what you're building.

Step 2 of 4 — See5 min

Four more models — click each for its real differentiator

DEEPSEEK
Strong reasoning per dollar, open-weight
Released with open weights, meaning the model itself can be downloaded and run on your own infrastructure rather than only accessed through an API. This matters for teams with strict data-residency requirements, or anyone optimizing hard for cost at scale.
GEMINI
Native multimodal + very large context window
Built from the ground up to handle text, images, and video together, and supports an unusually large context window — relevant when a task genuinely needs to reason over a large document or codebase in a single pass, not chunked pieces.
KIMI (Moonshot AI)
Long-context specialist
Specifically optimized for very long input — useful for tasks like analyzing an entire book-length document or a large log file in one go, where fitting everything into context without chunking meaningfully changes what's possible.
GROK
Real-time access to X/social data
Its differentiator isn't raw reasoning ability — it's built-in access to real-time social platform data, relevant specifically for tasks that need to reason about what's happening right now on that platform, not general knowledge.
