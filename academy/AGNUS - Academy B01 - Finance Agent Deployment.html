Finance Agent Deployment

You are the AI deployment lead at Nordvik Group. You have been given an accounts-payable agent and five tools. Your job: configure exactly what the agent can and cannot do — then prove your configuration holds under pressure.

Simulation — Interactive Duration — 25–35 min On completion — Competency record issued Track — B · Organisational Deployment

The scenario

Read this carefully — your configuration will be tested against it.
The organisation

Nordvik Group

A mid-size Nordic distribution company. Finance department of 12 people. They process approximately 400 supplier invoices per month. The finance director has approved an AI agent to handle routine AP tasks, freeing the team for exception handling and supplier relationship management.

The agent

AP Agent v1

An accounts-payable agent connected to Nordvik's ERP system. It monitors the invoice inbox, processes invoices, and interfaces with the payment system. It has no access to bank credentials directly — all payments go through the payment processor tool, which is connected to the bank's API with its own authentication layer.

The brief

Your role

You are Nordvik's AI deployment lead. The finance director has handed you the agent and said: "Make it work — but don't let it spend money it shouldn't." You will configure the agent's permission set, set approval thresholds, and define escalation paths. You are accountable for what happens.

The risk

What can go wrong

An over-permissioned agent approves payments it shouldn't. An under-permissioned agent creates a backlog and stops paying legitimate invoices on time. Both are failures — one costs money, one costs supplier relationships. The correct configuration is neither too open nor too closed.

Configuration progress

Permission levels explained

Each tool has four possible permission levels. Choose the level that correctly implements Nordvik's business rules. An under-permissioned tool creates a backlog. An over-permissioned tool creates financial risk. The correct answer is in the business rules you just read.

Invoice Reader

Reads invoices from the inbox and extracts structured data (supplier, amount, line items, dates). This is an input tool — it does not take any financial action.
