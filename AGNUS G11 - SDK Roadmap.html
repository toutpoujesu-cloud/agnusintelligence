articles.list() and articles.get(article_id)
Pydantic model: Article with all fields typed
Pagination helper: articles.iter() auto-pages
v0.2 Intelligence + Sources Planned
intelligence.list() with date filtering
sources.list() and sources.register()

articles.create() and articles.publish(article_id)
intelligence.submit()

Progress bar in CLI for long-running pipeline jobs

@agnus/sdk

Type-safe client with React hooks and Next.js integration. ESM + CJS builds. Targets TypeScript 5.0+ / Node 18+.

v0.1 Foundation First release
Authentication — API key via constructor or AGNUS_API_KEY env var
Base fetch client with error normalisation and TypeScript error types
articles.list(params?) and articles.get(articleId)
Full TypeScript interfaces: Article, ArticleListParams, ArticleList
ESM + CJS dual build. Tree-shakeable. Zero runtime dependencies.
v0.2 Intelligence + Sources Planned
intelligence.list() and sources.list()
Interfaces: IntelligenceRecord, Source
Pagination cursor utility: paginate(fn, params) async generator
Node.js + Edge Runtime compatible (no Node-only APIs)
v0.3 Write Operations Planned
articles.create(body) and articles.publish(articleId)
intelligence.submit(body) and sources.register(body)
Typed request bodies with required/optional distinction
Error classes: AgnusError, AgnusValidationError, Agnus401Error
v0.4 React Hooks Planned
useArticles(params?) hook — list with loading/error state
useArticle(id) hook — single article
useIntelligence(params?) hook — feed with auto-refresh
Exported from @agnus/sdk/react subpath (tree-shakes React from server builds)
Next.js Server Components compatible wrapper (@agnus/sdk/next)
v1.0 Production Target: Q2 2027
Full endpoint coverage — all 10 Control Plane endpoints
Pipeline resource: pipeline.trigger(), pipeline.status(jobId)
Webhook signature verification utility
Bundle size ≤ 12 kB minified + gzipped (core, no React)

Usage examples

Python — list EU AI Act articles and export standfirsts
from agnus import Agnus

client = Agnus()  # reads AGNUS_API_KEY from environment

# Paginate through all EU AI Act articles
for article in client.articles.iter(pillar="EU AI Act"):
    print(f"{article.article_id} · {article.title}")
    print(f"  {article.standfirst[:120]}...")

# Submit an intelligence record
record = client.intelligence.submit(
    title="EDPB publishes guidance on AI data minimisation",
    summary="The European Data Protection Board has published...",
    jurisdiction="European Union",
    category="guidance",
    significance="high",
    source_url="https://edpb.europa.eu/..."
)
print(record.record_id)  # IR-000124
TypeScript — React hook usage in a compliance dashboard
import { useArticles, useIntelligence } from '@agnus/sdk/react';

export function ComplianceDashboard() {
  const { data: articles, isLoading } = useArticles({
    pillar: 'EU AI Act',
    jurisdiction: 'European Union',
    limit: 10,
  });

  const { data: feed } = useIntelligence({
    since: '2026-09-01',
    significance: 'high',
  });

  if (isLoading) return <div>Loading...</div>;

  return (
    <main>
      <section>
        {articles?.items.map(a => (
          <ArticleCard key={a.article_id} article={a} />
        ))}
      </section>
      <aside>
        {feed?.items.map(r => <IntelligenceItem key={r.record_id} record={r} />)}
      </aside>
    </main>
  );
}
TypeScript — Next.js Server Component (no hook needed)
import { Agnus } from '@agnus/sdk/next';

const agnus = new Agnus();

export default async function ResearchPage() {
  const { items } = await agnus.articles.list({ pillar: 'AI Governance', limit: 20 });

  return (
    <ul>
      {items.map(a => <li key={a.article_id}>{a.title}</li>)}
    </ul>
  );
}

Delivery milestones

Control Plane API live (G10)

Prerequisite gate

SDK development begins only once the Control Plane API is in production (Phase C). Both SDKs start at v0.1 simultaneously.

v0.1 — both SDKs

First external release

Python on PyPI as agnus, TypeScript on npm as @agnus/sdk. Read access to articles only. Unlocks first beta API partners.

v0.3 — both SDKs

Write operations

Partners can ingest articles, submit intelligence records, and register sources programmatically. Enables automated compliance workflows.

v0.4 — TypeScript

React hooks

Frontend teams can build compliance dashboards on AGNUS data with minimal boilerplate. Target: 3 partner integrations live before v1.0.

v1.0 — both SDKs · Q2 2027

Production release

Full endpoint coverage, docs, test coverage ≥ 90%. Marks the AGNUS developer platform as generally available.
