AGNUS Control Plane API

10 endpoints covering article management, intelligence records, reviews, agents, source registry, and pipeline operations. Read endpoints are available to all API subscribers. Write endpoints require the control-plane:write scope.

Base URL https://api.agnus.io/v1 Phase C — not yet live
Authentication

All requests require a bearer token in the Authorization header: Authorization: Bearer <API_KEY>. API keys are issued per organisation. Keys carry one or more scopes: read (all GET endpoints), control-plane:write (POST, PUT, DELETE), pipeline:trigger (pipeline operations). Rate limits: 120 requests / minute on read; 20 / minute on write.

GET /articles List research articles

Returns a paginated list of research articles. Filterable by pillar, jurisdiction, content type, status and publication date. Sorted by published descending by default.

Query parameters

NameTypeRequiredDescription
pillarstringoptionalFilter by pillar slug: eu-ai-act, ai-governance, ai-agents, ai-security, ai-audit, data-governance, standards, countries
jurisdictionstringoptionalISO country code or International / European Union
statusstringoptionalcurrent · updated · archived
limitintegeroptional1–100. Default: 20
offsetintegeroptionalPagination offset. Default: 0

Response 200

application/json
{
  "total": 85,
  "limit": 20,
  "offset": 0,
  "items": [

      "article_id": "AR-000142",

      "pillar": "EU AI Act",

      "status": "current",
      "published": "2026-07-18",
      "reading_time": 12,
      "jurisdiction": "European Union"
    }
  ]
}

POST /articles Register article — requires control-plane:write

Registers a new article in the AGNUS data layer. The article enters draft status and must be explicitly published via POST /articles/{id}/publish. The system assigns the next available AR-XXXXXX ID.

Request body — application/json

FieldTypeRequiredDescription
slugstringrequiredURL-safe identifier, e.g. human-oversight-article-14
pillarstringrequiredResearch pillar name
subtopicstringrequiredSub-topic within the pillar
titlestringrequiredFull article title
content_typestringrequiredanalysis · guide · reference · deep-dive
standfirststringrequiredOne-paragraph summary for feeds and metadata
jurisdictionstringrequiredISO country code, European Union or International
actors_affectedstring[]requiredArray of actor types: Provider, Deployer, Board, etc.
authorstringoptionalAuthor slug. Defaults to API key owner.

Response 201

application/json
{ "article_id": "AR-000597", "status": "draft", "created_at": "2026-09-19T14:22:00Z" }

Error responses

400 Bad Request 401 Unauthorized 422 Validation Error
POST /articles/{article_id}/publish Publish article — requires control-plane:write

Moves an article from draft to current status. Sets published timestamp to now. Triggers the article to appear in the live Research feed and Intelligence tickers within 60 seconds.

Response 200

application/json
{ "article_id": "AR-000597", "status": "current", "published": "2026-09-19" }

Error responses

401 Unauthorized 404 Not Found 422 — Article already published

GET /intelligence List intelligence records

Returns the AGNUS intelligence feed. Each record is a regulatory event, enforcement action, court decision, or guidance publication with AGNUS editorial classification. Filterable by jurisdiction, category, and date range.

Query parameters

NameTypeRequiredDescription
jurisdictionstringoptionalISO code or region name
categorystringoptionalregulation · enforcement · guidance · litigation
sincedateoptionalISO 8601 date — returns records on or after
limitintegeroptional1–100. Default: 20

Response 200

application/json
{ "total": 3, "items": [{ "record_id": "IR-000117", "title": "EU GPAI Codes of Practice — Final Round", "jurisdiction": "European Union", "category": "regulation", "published": "2026-09-01", "significance": "high" }] }
POST /intelligence Submit intelligence record — requires control-plane:write

Submits a new intelligence record to the AGNUS feed. Used by the Intelligence Monitoring Agent and authorised partner systems. Records enter a brief editorial review queue before publication (automated for Agent submissions, manual for API submissions).

Request body — application/json

FieldTypeRequiredDescription
titlestringrequiredHeadline for the intelligence record
summarystringrequired2–4 sentence editorial summary
jurisdictionstringrequiredISO code or region
categorystringrequiredregulation · enforcement · guidance · litigation
significancestringrequiredlow · medium · high · critical
source_urlstringrequiredPrimary source URL
event_datedateoptionalWhen the event occurred. Defaults to today.

Response 201

application/json
{ "record_id": "IR-000124", "status": "pending_review" }

Sources

2 endpoints
GET /sources List registered sources

Returns the AGNUS source registry. Sources are primary regulatory documents, court decisions, official guidance and academic papers that underpin the research articles. Each source carries an authority classification and verifiability status.

Query parameters

NameTypeRequiredDescription
authoritystringoptionalprimary · guidance · standard · academic
article_idstringoptionalReturn only sources cited by this article
limitintegeroptional1–100. Default: 50

Response 200

application/json
{ "total": 76, "items": [{ "source_id": "SRC-0001", "title": "Regulation (EU) 2024/1689 — AI Act", "authority": "primary", "verified": true, "url": "https://eur-lex.europa.eu/..." }] }
POST /sources Register source — requires control-plane:write

Registers a new source in the AGNUS source registry. Assigns the next available SRC-XXXX ID. Sources are available immediately for citation in new articles via the sources field on POST /articles.

Request body — application/json

FieldTypeRequiredDescription
titlestringrequiredFull title of the source document
authoritystringrequiredprimary · guidance · standard · academic · supporting
urlstringrequiredCanonical URL of the source
organisationstringoptionalIssuing body, e.g. European Commission, NIST
published_datedateoptionalDate of source publication

Response 201

application/json
{ "source_id": "SRC-0077", "verified": false, "created_at": "2026-09-19T14:30:00Z" }

Pipeline

2 endpoints
POST /pipeline/trigger Trigger pipeline run — requires pipeline:trigger

Triggers an article pipeline run for one or more articles. The pipeline validates content, runs the editorial AI layer, checks cross-references, and queues the article for human review. Returns a job_id for status polling.

Request body — application/json

FieldTypeRequiredDescription
article_idsstring[]requiredOne or more AR-IDs to process
modestringoptionalvalidate (dry run) · full (default)

Response 202

application/json
{ "job_id": "pipe_9f3a2c", "status": "queued", "article_count": 3 }
GET /pipeline/{job_id} Get pipeline job status

Returns the current status of a pipeline job. Poll every 5–10 seconds until status is completed, failed or pending_review.

Response 200

application/json
{
  "job_id": "pipe_9f3a2c",
  "status": "pending_review",
  "started_at": "2026-09-19T14:31:00Z",
  "articles": [
    { "article_id": "AR-000597", "status": "pending_review", "validation_score": 0.94 }
  ]
}
